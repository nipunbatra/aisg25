# CS 691 · AI for Social Good (2025)

Course website for CS 691 AI for Social Good at IIT Gandhinagar, Semester II 2024–25:
<https://nipunbatra.github.io/aisg25/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Actions renders it and publishes it to the
`gh-pages` branch (`quarto publish gh-pages`) on every push to `main`.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, session overview, domains and methods, questions, references, guest lecturers |
| `schedule.qmd` | Lectures: instructor lectures, paper presentations (with the papers) and guest talks |
| `assessment.qmd`, `_dates.qmd` | Grading, paper presentation criteria, the paper replication project and every dated event |
| `seminar.qmd` | Guest talks: abstracts and biosketches |
| `brainstorm.qmd` | In-class questions and exercises on reviewing AI for social good papers |
| `grading.qmd`, `tentative.qmd`, `faq.qmd`, `quizzes.qmd`, `exams/prereq.qmd` | Redirects from old URLs |
| `styles.scss`, `course.scss` | Shared theme (`styles.scss` is identical to dl-2026) and small additions |
| `rail.html`, `course-theme.html`, `course-tools.html` | Side rail, light and dark switch, footer, copy-link buttons and date handling |

Preview locally with `quarto preview`.
